# Security policy

Clastor is experimental and intended for trusted local environments. The current service has no authentication, release authorization, or fencing. See the documented limits before deploying it. [README](README.md)

Use **Report a vulnerability** on the repository's Advisories page to send a private report. Include the affected revision, the backend, the observed impact and steps to reproduce. The maintainer, `@rusanoph`, reviews reports in GitHub. Keep vulnerability details out of public issues and pull requests. [Report privately](https://github.com/rusanoph/clastor-distributed-lock/security/advisories/new)
